\subsection{Reproducing the Numerical Results}
The code to reproduce all the results is in \ref{ref:analysis-repository}. Follow the instructions in the HOWTO.md file to generate the figures, models and analyses.
You will need to clone the repository to run the code. The code uses make and python.
In addition you need to have access to a Snowflake role that has access to the following tables:
\begin{verbatim}
 EDLDB.PET_HEALTH_ANALYTICS_SANDBOX.FCT__TASKS_LIFECYCLE
 EDLDB.BT_HCA_HCDM.RXP_RX_USAGE_ACTIONS
 CHEWYBI.CUSTOMER_PETPROFILES
 EDLDB.PDM.PRODUCT
 EDLDB.BT_HCA_HCDM.RXP_PRESCRIPTIONS
 EDLDB.PET_HEALTH_ANALYTICS_SANDBOX.FCT__RX_RESULT_FIELD_CHANGE_SUMMARY
\end{verbatim}
and the pet health analytics sandbox in the dev environment;
\begin{verbatim}
 EDLDB_DEV.PET_HEALTH_ANALYTICS_SANDBOX
\end{verbatim}
to generate transient tables.

\subsection{Data Preliminaries and Assumptions}
The study considers DUR tasks recorded in
\texttt{EDLDB.PET\_HEALTH\_ANALYTICS\_SANDBOX.FCT\_\_TASKS\_LIFECYCLE}
between 2026-02-01 and 2026-08-01.

Since the analysis is interested in figuring out the effect of a
pharmacist repeatedly doing similar work, the study excludes DUR tasks
that required a follow-up. We assume failed DURs break the
concentration of the pharmacist and the effect of doing consecutive
similar tasks.  Table~\ref{tab:dur-handoff-type-processing} shows the
handoff-type distribution for all DUR tasks.

Only the actual time spent on the DUR is used
(\texttt{DWELL\_IN\_PROGRESS\_TO\_CLOSED\_SECONDS}). In the remainder
of this report, that duration is called processing time or process
duration.
