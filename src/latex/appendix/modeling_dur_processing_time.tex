\subsection{Modeling DUR Processing Time}\label{modeling-dur-processing-time}
In this section, we develop a model that incorporates the following factors
\begin{itemize}
\item whether the task was preceded by a task of similar cohort
\item pharmacist
\item pet type
\item if there were alterations done during the DUR process
\item date effects
\item approval and prescription channels
\item cohort
\item week of day
\end{itemize}

We find that being preceded by a task of the same cohort reduces DUR
duration about 3.4\% assuming everything else stays the same with the
task.
We note that this is not a causal model nor is the data obtained
from a randomized controlled experiment setup. Even though extreme
care has been taken to reduce confounding, it may still be present.

\subsubsection{Data}
The model uses 3,433,218 DUR tasks with durations below the global 95th-percentile cutoff of
156.608019 seconds.

Let \(Y_i\) be duration in seconds, \(S_i\) the
task's position in its same-cohort batch, and \(L_i\) the batch length.
The sequence indicators are
\[
P_i=\mathbf{1}(L_i>1\land S_i>1),\qquad
F_i=\mathbf{1}(L_i>1\land S_i<L_i).
\]
\texttt{SAME\_PRECEDING} (\(P_i\)) means an earlier task in the
same-cohort batch precedes task \(i\). \texttt{SAME\_FOLLOWING}
(\(F_i\)) means a later task in that batch follows it. Consecutive
tasks for a user must have no break longer than one hour; overlapping
and failed DUR tasks are excluded. Both indicators can equal one.
Missing parent part numbers form a separate category.

\subsubsection{Model}
The outcome is the natural logarithm of duration:
\[
\begin{aligned}
\log(Y_i)={}&\alpha+\beta_P P_i+\beta_F F_i+\beta_C C_i
 +\gamma_{c_i}+\delta_{p_i}+\theta_{w_i}\\
&+\phi_{a_i}+\psi_{s_i}
 +b_{u(i)}+h_{d(i)}+q_{r(i)}+\epsilon_i .
\end{aligned}
\]
\begin{itemize}
\item \(Y_i\): positive imputed DUR duration, in seconds, for task \(i\).
\item \(\alpha\): global intercept for the reference categories, zero
indicators, and zero random intercepts.
\item \(P_i,F_i\): same-preceding and same-following indicators above;
\(\beta_P,\beta_F\) are their conditional log-duration coefficients.
\item \(C_i=\mathbf{1}(N_i>0)\): whether task \(i\) has at least one
correction; \(\beta_C\) is its coefficient.
\item \(\gamma_{c_i},\delta_{p_i},\theta_{w_i},\phi_{a_i},\psi_{s_i}\):
additive fixed effects for cohort, pet type, weekday, approval channel,
and prescription source. Their references are Cohort 1, Dog, Sunday,
\texttt{PH}, and \texttt{PRACTICE\_HUB}. There are no fixed-effect
cells or interactions.
\item \(b_{u(i)},h_{d(i)},q_{r(i)}\): crossed random intercepts for user,
process date, and parent part number. They are independent normals
with mean zero and variances \(\sigma_u^2,\sigma_d^2,\sigma_r^2\).
\item \(\epsilon_i\): independent normal task residual with mean zero
and common variance \(\sigma_e^2\).
\end{itemize}

\subsubsection{Numerical procedure}
The global approximate 95th-percentile cutoff is applied to all
otherwise eligible positive durations; equality with the cutoff is
excluded. Retained durations are log-transformed. Categorical
variables are encoded as contrasts to the stated references and the
three grouping variables as crossed random intercepts.

Restricted maximum likelihood (REML) estimates fixed coefficients
and variance components. The implementation accumulates
cross-products and profiles out fixed coefficients and residual
variance at each candidate set of random-effect variance ratios.
Cholesky solves evaluate the profiled objective; bounded L-BFGS-B
minimizes it on the log-variance-ratio scale. The fit converged.

Fixed-effect standard errors come from the fitted covariance matrix.
The two-sided \(p\)-values and 95\% confidence intervals use normal
Wald approximations, with \(z=\widehat\beta/
\mathrm{SE}(\widehat\beta)\). A coefficient is marked significant when
its interval excludes zero. Random-intercept SD intervals use observed
information on the log-SD scale; the residual-SD interval uses a
chi-square approximation. All estimates and SDs are on the log scale.

\subsubsection{Interpretation and assumptions}
Exponentiating a sequence coefficient gives its conditional duration
ratio: \(\exp(\widehat\beta_P)=0.965730\). The model assumes additive
effects, independent normally distributed random intercepts and
residuals, and common residual variance.
