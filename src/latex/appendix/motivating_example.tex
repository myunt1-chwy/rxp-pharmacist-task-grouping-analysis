At first glance, it can be seen that if the pharmacist updates prescription information, highly likely, the DUR process takes longer. The 13 DUR long session takes place within 7 minutes and the DUR durations vary between 6 and 97 seconds suggesting that there is significant unaccounted variation in time measurements. It is hard to discern any pattern by inspection that suggests any benefit of grouping tasks together.

In the second sequence, the prescriptions are for cats. Note that for the same MC3 and cohort (cohort 1 in this case), pet and even part number (158995) we can expect significant variation. In this case, it can be seen that the duration varies between 3 and 50 seconds for the same part number and pet type for the same pharmacist in a 4 minute time span.
