\subsection{Example Sequences of Similar DUR Tasks}
In this section, two task sequences from the same user are examined.

Both sequences consider prescriptions with Parasiticide as merchandizing category level 3 (MC3)  and with  approval channel as Practice Hub. All prescriptions belong to cohort 1. The ppdated fields column contains the the data the pharmacist altered during the DUR.

In the first sequence, all the prescriptions are for dogs. (Table~\ref{tab:motivating-dogs}). If the pharmacist updates prescription information, the DUR process highly likely takes longer. The 13 DUR long task sequence takes place within 7 minutes and the DUR durations vary between 6 and 97 seconds suggesting that there is significant variation. It is hard to discern any pattern that suggests any benefit of grouping tasks together.

In the second sequence, the prescriptions are for cats (Table~\ref{tab:motivating-cats}). Note that for the same MC3 and cohort (cohort 1 in this case), pet and even part number (158995) we can expect significant variation. In this case, it can be seen that the duration varies between 3 and 50 seconds for the same part number and pet type and  the same pharmacist in a 4 minute time span.
